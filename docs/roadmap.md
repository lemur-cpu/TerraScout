# Roadmap

## Working now

- Local DEM load/validate, relief layers, conventional detection, CLI analyze
- Size-capped USGS 3DEP ImageServer subsets and TNM product search
- SQLite candidate registry and localhost dashboard loader
- Six-agent swarm with real tools and no LLM key
- Synthetic benchmark JSON

## Not done (do not treat as shipped)

- OpenTopography downloads (API key required; not bundled)
- NASA Earthdata granule download (CMR search not wired in CLI yet)
- PDAL EPT streaming execution (spec generated; PDAL extra optional)
- LangGraph backend (custom orchestrator is the default)
- Trained archaeological detector (no labeled field dataset, no training run)
- Calibrated P(archaeological) scores
- Public hosted dashboard (intentionally out of scope)
- GitHub private remote creation from the Cursor GitHub App installation token
